# 🧩 Python 魔术方法速查表

| 功能类别         | 魔术方法                                        | 说明                 | 示例                          |
| ------------ | ------------------------------------------- | ------------------ | --------------------------- |
| **对象创建与初始化** | `__new__(cls, ...)`                         | 创建对象，返回实例          | `obj = cls.__new__(cls)`    |
|              | `__init__(self, ...)`                       | 初始化对象              | `obj = MyClass(10)`         |
|              | `__del__(self)`                             | 对象被销毁时调用           | `del obj`                   |
| **对象表示**     | `__str__(self)`                             | `print(obj)` 输出内容  | `return "MyClass instance"` |
|              | `__repr__(self)`                            | 交互模式或调试输出          | `return "MyClass(10)"`      |
| **运算符重载**    | `__add__(self, other)`                      | `+` 运算             | `obj1 + obj2`               |
|              | `__sub__(self, other)`                      | `-` 运算             | `obj1 - obj2`               |
|              | `__mul__(self, other)`                      | `*` 运算             | `obj1 * obj2`               |
|              | `__truediv__(self, other)`                  | `/` 运算             | `obj1 / obj2`               |
|              | `__floordiv__(self, other)`                 | `//` 运算            | `obj1 // obj2`              |
|              | `__mod__(self, other)`                      | `%` 运算             | `obj1 % obj2`               |
|              | `__pow__(self, other)`                      | `**` 运算            | `obj1 ** 2`                 |
|              | `__eq__(self, other)`                       | `==` 比较            | `obj1 == obj2`              |
|              | `__ne__(self, other)`                       | `!=` 比较            | `obj1 != obj2`              |
|              | `__lt__(self, other)`                       | `<` 比较             | `obj1 < obj2`               |
|              | `__le__(self, other)`                       | `<=` 比较            | `obj1 <= obj2`              |
|              | `__gt__(self, other)`                       | `>` 比较             | `obj1 > obj2`               |
|              | `__ge__(self, other)`                       | `>=` 比较            | `obj1 >= obj2`              |
| **函数调用**     | `__call__(self, ...)`                       | 对象可以像函数一样调用        | `obj(10)`                   |
| **容器操作**     | `__getitem__(self, key)`                    | `obj[key]` 访问元素    | `obj[0]`                    |
|              | `__setitem__(self, key, value)`             | `obj[key] = value` | `obj[0] = 10`               |
|              | `__delitem__(self, key)`                    | `del obj[key]`     | `del obj[0]`                |
|              | `__len__(self)`                             | `len(obj)`         | `len(obj)`                  |
|              | `__iter__(self)`                            | 迭代对象               | `for x in obj:`             |
|              | `__next__(self)`                            | 迭代器返回下一个值          | `next(obj)`                 |
| **属性访问**     | `__getattr__(self, name)`                   | 访问不存在的属性时调用        | `obj.foo`                   |
|              | `__setattr__(self, name, value)`            | 设置属性值              | `obj.foo = 10`              |
|              | `__delattr__(self, name)`                   | 删除属性               | `del obj.foo`               |
| **上下文管理**    | `__enter__(self)`                           | `with` 语句进入时调用     | `with obj as x:`            |
|              | `__exit__(self, exc_type, exc_val, exc_tb)` | `with` 语句退出时调用     | 异常处理/资源释放                   |

### 🔹 使用小技巧

* **查看对象所有魔术方法**：

```python
dir(object)
```

* **魔术方法不一定要全部实现**，按需重载即可，比如你只想让对象可迭代，就实现 `__iter__` 和 `__next__`。
