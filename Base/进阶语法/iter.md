### 🔑 自定义迭代器什么时候用？

1. **自定义生成逻辑**

   * 需要生成特殊序列（斐波那契、素数、偶数等）。
   * 内置的 `range` / `list` 不够用时。

2. **惰性计算，节省内存**

   * 数据量很大（如 10 亿个数），不能一次性存到内存。
   * 迭代器按需计算，每次只生成一个值。

3. **封装复杂逻辑**

   * 比如逐行读取大文件、分页获取数据库数据。
   * 对外只暴露 `for...in` 接口，内部细节用户不需要关心。

4. **兼容 Python 的迭代协议**

   * 实现 `__iter__` 和 `__next__` 后，你的对象就能用：

     * `for...in` 遍历
     * `list(obj)` 转换
     * `sum(obj)`、`max(obj)` 等内置函数

---

📌 **一句话总结**：
自定义迭代器的作用是 **按需、逐个生成数据**，尤其适合 **大数据量** 或 **特殊规则的序列**，还能让自定义对象像 Python 内置容器一样被 `for` 循环、`list()` 等函数直接使用。
