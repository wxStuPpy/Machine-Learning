## 1. 正则化 (Regularization)

**核心思想**：在损失函数里加入约束，避免模型过拟合（即在训练集上表现好，但在测试集上泛化差）。

* 目的：让模型不要过度依赖某些特征，增强泛化能力。
* 典型做法：

  * **L1 正则化（Lasso）**：在损失函数里加上权重绝对值和
    [
    L = \text{loss} + \lambda \sum |w|
    ]
    → 会产生稀疏解，部分权重变为 0，相当于特征选择。
  * **L2 正则化（Ridge）**：在损失函数里加上权重平方和
    [
    L = \text{loss} + \lambda \sum w^2
    ]
    → 会抑制权值过大，权值趋向均匀分布。

## 2. Batch Normalization (BN)

**核心思想**：在每一层对输入进行标准化，让其均值为 0，方差为 1，然后再通过可学习参数恢复缩放和平移。

* 步骤：

  1. 对 mini-batch 的激活值计算均值和方差。
  2. 标准化：
     [
     \hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}
     ]
  3. 缩放 + 平移（可学习参数 γ, β）：
     [
     y = \gamma \hat{x} + \beta
     ]

* 优点：

  * 缓解梯度消失/爆炸问题。
  * 提高学习速度，可以使用更大学习率。
  * 带来一定的正则化效果。

---

## 3. 权值衰减 (Weight Decay)

其实就是 **L2 正则化** 在神经网络中的常见说法。

* 更新公式（以 SGD 为例）：
  [
  w \leftarrow w - \eta (\nabla L(w) + \lambda w)
  ]
  → 等价于在训练过程中不断“拉小”权重，防止过拟合。

* 在 PyTorch 里，`optimizer = torch.optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-4)` 就是启用权值衰减。

---

## 4. Dropout

**核心思想**：在训练时，随机“丢弃”一部分神经元（设置为 0），让网络不要依赖某几个特定神经元。

* 训练时：

  * 对某一层的神经元，以概率 `p` 保留，其他设为 0。

* 测试时：

  * 使用所有神经元，但把权重缩放（乘以 `p`）。

* 优点：

  * 有效减少过拟合。
  * 类似于“训练了很多子网络的集成”。

---

📌 总结一下区别：

* **正则化（L1/L2）**：通过惩罚项控制权重。
* **BN**：对层输入做归一化，稳定训练过程。
* **权值衰减**：就是 L2 正则化，常用在神经网络里。
* **Dropout**：训练时随机屏蔽部分神经元，增加模型鲁棒性。
