
### 一、模式切换
- `Esc`：从编辑模式切换到**命令模式**（单元格边框为蓝色）
- `Enter`：从命令模式切换到**编辑模式**（单元格边框为绿色）


### 二、命令模式快捷键（按 `Esc` 后生效）
#### 1. 单元格操作
- `A`：在当前单元格**上方**插入新单元格
- `B`：在当前单元格**下方**插入新单元格
- `DD`（连续按两次 D）：删除当前单元格
- `Z`：撤销删除操作
- `X`：剪切当前单元格（可粘贴）
- `C`：复制当前单元格
- `V`：在当前单元格下方粘贴
- `Shift + V`：在当前单元格上方粘贴
- `Shift + M`：合并当前单元格与下方单元格
- `Ctrl + Shift + -`：从光标处拆分当前单元格（需先进入编辑模式定位光标）

#### 2. 单元格类型切换
- `Y`：将单元格转为**代码单元格**（Code）
- `M`：将单元格转为** markdown 单元格**（可写文本、公式）
- `R`：将单元格转为**原始文本单元格**（Raw，不执行代码）

#### 3. 运行与移动
- `Shift + Enter`：运行当前单元格，并跳到下一个单元格（若无则新建）
- `Ctrl + Enter`：运行当前单元格，不跳转
- `Alt + Enter`：运行当前单元格，并在下方新建一个单元格
- `↑`/`↓` 箭头：上下移动选中的单元格
- `Shift + ↑`/`Shift + ↓`：选中多个连续单元格


### 三、编辑模式快捷键（按 `Enter` 后生效，类似普通文本编辑）
#### 1. 文本编辑
- `Ctrl + A`：全选
- `Ctrl + Z`：撤销
- `Ctrl + Shift + Z` 或 `Ctrl + Y`：重做
- `Ctrl + C`/`Ctrl + X`/`Ctrl + V`：复制/剪切/粘贴
- `Ctrl + D`：删除当前行
- `Ctrl + Shift + -`：拆分单元格（从光标处）
- `Tab`：代码自动补全或缩进
- `Shift + Tab`：显示函数/方法的文档说明（参数提示）

#### 2. 运行相关
- `Shift + Enter`：运行单元格并跳转（同命令模式）
- `Ctrl + Enter`：运行单元格不跳转（同命令模式）


### 四、其他实用操作
- **查找与替换**：命令模式下按 `F`，或编辑模式下 `Ctrl + F`
- **重启内核**：命令模式下按 `00`（连续按两次 0），或菜单栏 `Kernel -> Restart`
- **显示所有快捷键**：命令模式下按 `H`，会弹出快捷键对照表（必备！）
- **切换行号**：命令模式下按 `L`（单次显示，再按隐藏）


### 五、JupyterLab 额外快捷键（更强大的界面）
- `Ctrl + Shift + P`：打开命令面板（搜索并执行所有操作，类似 VS Code）
- `Ctrl + B`：显示/隐藏左侧文件导航栏
- `Ctrl + Shift + [ ` / `]`：折叠/展开代码块（编辑模式）
